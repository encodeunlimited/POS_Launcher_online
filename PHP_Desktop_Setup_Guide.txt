PHP Desktop Setup Guide (Sinhala)

1. PHP Desktop eka Download Karaganna
PHP Desktop eka dan update wenne unge GitHub eke. Eken official latest version eka ganna puluwan.
- Me link ekata yanna: https://github.com/cztomczak/phpdesktop/releases
- Eke thiyena latest release eken Windows walata hariyana .zip file eka download karaganna (Godak welawata phpdesktop-chrome-...-php-....zip kiyala thiyenne).

2. Extract Karaganna
- Download wechcha .zip file eka oyata ona folder ekakata (Eg: Desktop eke hari C: drive eke hari) right-click karala Extract Here denna.

3. Setup Eka Hada Ganna (Oge project eka danna)
Extract karama ena folder eke godak files thiyenawa. Eke thiyena pradhana dewal thama me:
- phpdesktop-chrome.exe - Meka thama app eka run karana eka.
- www/ folder eka - Me folder eka athulata thama oyage PHP, HTML, CSS files danna ona.
- settings.json - App eke settings wenas karanna ona nam meka use karanna puluwan.

Kohomada karanne:
- Extract karapu folder eke thiyena www kiyana folder eka open karanna.
- Eke athule thiyena default files (index.php wage dewal) tika delete karanna hari wenama thanakata ganna.
- Eeta passe oyage hadapu PHP project eke thiyena okkoma files tika me www folder eka athulata paste karanna. (Make sure oyage main file eka index.php hari index.html kiyala thiyenawa kiyala).

4. Settings Wenas Karanna (Optional)
App eke title eka hari port eka hari wenas karanna ona nam:
- Folder eke thiyena settings.json file eka Notepad hari VS Code eken hari open karaganna.
- Eke "main_window" kiyana eka yatathe thiyena "title" ekata oyage app eke nama danna puluwan. (Eg: "title": "My POS System")
- Save karala close karanna.

5. App eka Run Karanna!
- Okkoma files dapu gaman, folder eke thiyena phpdesktop-chrome.exe kiyana file eka double-click karala run karanna.
- Dan oyage PHP project eka Desktop app ekak widiyata open wei!
